# Materiały ROPS Kraków — konkursy grantowe na innowacje społeczne

Publiczne dokumenty pobrane ze strony rops.krakow.pl 2026-10-03 jako źródło danych dla Modułu 3 (Kreator pomysłów, generator wniosków). Wszystkie nabory są **zakończone** — dokumenty służą jako wzorzec struktury wniosku, kryteriów oceny i słowników, nie jako aktualne ogłoszenie.

- Raport z researchu (ustalenia, struktura wniosków, kryteria, definicje, różnice między naborami): [`RAPORT.md`](RAPORT.md)
- Obok każdego PDF/DOCX leży `.txt` z wyciągniętym tekstem (pdftotext / docx → tekst). Układ graficzny (np. Social Canvas) jest w `.txt` częściowo zniekształcony — w razie wątpliwości patrz na PDF.
- Wzór formularza przesłany na Discordzie HackYeah (`za._3._Formularz_aplikacyjny_wzor.pdf`) jest bajtowo identyczny z `iws2/iws2_formularz.pdf` (md5 `55e60bc5…`).
- Regulamin Usługi Wrażliwej I i II to ten sam plik (identyczne md5) — trzymamy obie kopie dla porządku katalogów.

Prefiks plików do pobrania: `https://rops.krakow.pl/pliki-do-pobrania/`
